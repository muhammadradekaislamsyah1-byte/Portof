Ridera — Motorcycle Journey & Fuel Tracker

Platform web personal yang dibangun untuk mendokumentasikan setiap rute berkendara, riwayat touring, dan menghitung efisiensi konsumsi bahan bakar kendaraan secara matematis dan terstruktur.

Kategori Web Platform • Utility
Peran Full-stack Development
Database MySQL Relational
Implementasi Fitur & Logika:
  • Algoritma BBM: Kalkulasi otomatis rata-rata KM/Liter berdasarkan data pengisian tangki bensin dan selisih odometer.
  • Log Rute & Memori: Input titik awal, destinasi, kondisi cuaca, serta catatan kesan perjalanan.
  • Sistem Upload Media: Kompresi dan validasi berkas foto dokumentasi sebelum disimpan ke direktori hosting.
  • Backend Ringan: Menggunakan arsitektur Native PHP prosedural yang dioptimalkan untuk respons server cepat.
Tech Stack:
PHP Native MySQL Bootstrap 5 JavaScript SQL Logic

Sistem pemrosesan berkas spreadsheet berskala besar yang dirancang khusus untuk menangani ribuan baris data tanpa membebani kapasitas RAM server hosting murah.

Kategori Data Processing • Optimization
Fokus Utama Memory Handling & Indexing
Target Data Spreadsheet • SQL Records
Implementasi Fitur & Logika:
  • Batch / Chunk Processing: Pembacaan berkas data secara bertahap untuk mencegah error memory_limit exceeded.

Python PHP MySQL Spreadsheet Processing Database Indexing

HARDWARE EXPERIMENT

USB Step-Up Power Converter Module (5V → 9V/12V)

Eksperimen perakitan modul konversi voltase listrik DC-DC dari port USB 5V (seperti powerbank) menjadi tegangan keluaran stabil 9V dan 12V untuk kebutuhan suplai darurat router Wi-Fi atau perangkat lab.

Kategori Hardware • Electronics
Tegangan Masuk 5V DC (USB Standard)
Tegangan Keluar 9V • 12V DC Regulated
Fokus & Pengujian Teknis:
  • Sirkuit Konversi Daya: Pemanfaatan modul booster induktif untuk menaikkan level voltase dengan efisiensi tinggi.
  • Pengujian & Kalibrasi: Pengukuran keluaran tegangan menggunakan multimeter digital di bawah beban daya nyata.
  • Use Case Darurat: Memungkinkan router internet rumah tetap menyala menggunakan powerbank saat listrik padam.
  • Kombinasi Logika & Fisik: Melatih pemahaman arus, hambatan, dan toleransi komponen di luar dunia software.
Components & Tools:
DC-DC Step-Up USB Power Circuit Digital Multimeter Prototyping
